目标：在“全部”列表中，每张牌桌都能直接看到“我在该俱乐部的额度”，同时不打乱现有卡片层级。

A. 放在卡片底部横条

信息最完整，也最容易看懂，但会明显增加卡片高度。

0/9
#THtu*07MGM_1
德州 Club
在线 0 / 在桌 0
最低买入
1K
额度 12.5K

B. 放在右侧买入区下方

额度和最低买入放在一起，最符合“我够不够进这桌”的决策路径，改动也最小。

额度 12.5K
0/9
#THtu*07MGM_1
德州 Club
在线 0 / 在桌 0
最低买入
1K

C. 放在右上角悬浮标签

最省空间，但会和地区标签、状态标签一类信息争抢角落资源，易显得杂。

推荐

  • 优先选 B。它最贴近买入决策，不需要用户来回扫顶部俱乐部条和当前牌桌。
  • 在“全部”列表里，每张桌子的额度本来就对应不同俱乐部，放在右侧能自然形成“额度 vs 最低买入”的一组对照。

注意

  • 如果后端/前端入桌校验仍然使用全局 CREDIT，而卡片显示俱乐部 CREDIT，会造成展示和实际拦截不一致。
  • 额度文案建议用短标签，例如“额度”或“My Credit”，避免把右列撑宽。
